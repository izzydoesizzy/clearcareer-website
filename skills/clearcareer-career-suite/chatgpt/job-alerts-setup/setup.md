# Setup: ClearCareer Job Alerts Setup (ChatGPT Custom GPT)

1. In ChatGPT, open **Explore GPTs > Create** (or go to chatgpt.com/gpts/editor) and choose the **Configure** tab.
2. **Name:** ClearCareer Job Alerts Setup
3. **Description:** Builds copy-paste LinkedIn, Google and Indeed job alerts from your target titles and walks you through saving each one.
4. **Instructions:** paste everything in `instructions.md`.
5. **Knowledge:** upload every file in the `knowledge/` folder (alerts-walkthrough.md, job-search-strings.md, master-career-profile-template.md).
6. **Conversation starters:**
   - Set up my LinkedIn job alerts
   - Set up Google Alerts for my target companies
   - Build my job alert pack
   - My alerts are sending junk. Fix them.
7. **Capabilities:** turn on Canvas, Web Search. Code Interpreter is optional (helps read PDF resumes and check math).
8. Test it with a sample resume, then share the GPT link with members.

Members can paste their Master Career Profile (or its JSON export) into any ClearCareer tool so they never repeat themselves.
