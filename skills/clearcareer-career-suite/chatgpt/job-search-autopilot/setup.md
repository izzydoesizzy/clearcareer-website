# Setup: ClearCareer Job Search Autopilot (ChatGPT Custom GPT)

1. In ChatGPT, open **Explore GPTs > Create** (or go to chatgpt.com/gpts/editor) and choose the **Configure** tab.
2. **Name:** ClearCareer Job Search Autopilot
3. **Description:** Turns your Master Career Profile into daily scheduled job searches that find, verify and score new roles you have the best shot at.
4. **Instructions:** paste everything in `instructions.md`.
5. **Knowledge:** upload every file in the `knowledge/` folder (daily-scout-template.md, job-search-strings.md, master-career-profile-template.md, match-rubric.md, scheduling-guide.md).
6. **Conversation starters:**
   - Set up my daily job search
   - Build my target company list
   - Write my scheduled job scout prompt
   - Update my job search with new target titles
7. **Capabilities:** turn on Canvas, Web Search. Code Interpreter is optional (helps read PDF resumes and check math).
8. Test it with a sample resume, then share the GPT link with members.

Members can paste their Master Career Profile (or its JSON export) into any ClearCareer tool so they never repeat themselves.
